# Security Policy

## Supported versions

Security fixes are considered for the latest code on the `master` branch.
Older versions and forks are not maintained by this repository.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions,
or pull requests.

Email [sametakbal7@gmail.com](mailto:sametakbal7@gmail.com) with a description
of the vulnerability, steps to reproduce it, the affected version or commit,
and any relevant impact. Do not include real credentials or personal data.

If GitHub private vulnerability reporting is enabled for this repository,
you may also use the **Report a vulnerability** button on its Security page.
The maintainer will review reports on a best-effort basis and coordinate any
fix and public disclosure with the reporter.
